# Changelog

All notable changes to Keys Tools are recorded here. Release-plz maintains this
file from conventional commits.

## [0.1.0] - 2026-08-13

### Added

- `fetch`, a native system and CPU overview with styled, plain, and JSON output.
- `games`, a safe launcher for installed terminal games and bounded extension
  manifests.
- Release automation for native macOS, Linux, and Windows wheels through PyPI
  Trusted Publishing and GitHub releases.
- Release-plz semantic versioning, per-tool benchmarks, CodeQL scanning,
  dependency review, and contributor policies.
